Key insights from Manus's experience building AI agents - why context engineering has become the critical skill for 2025

I just read an excellent deep dive from the Manus team about context engineering for AI agents, and it’s packed with practical insights that anyone building AI systems should know about.

The Core Insight#

The Manus post1 opens with a striking observation: “Most agent failures are not model failures anymore, they are context failures.” We’ve moved past the era where model limitations were the primary bottleneck. Today’s models are remarkably capable—the challenge is giving them the right information at the right time.

They define context engineering as “the discipline of designing and building dynamic systems that provides the right information and tools, in the right format, at the right time, to give a LLM everything it needs to accomplish a task.” Notice that word: dynamic. This isn’t about crafting perfect static prompts—it’s about building systems that evolve context throughout an interaction.

Five Critical Production Lessons#

1. KV-Cache Optimization: The Hidden Performance Multiplier#

One of the most practical insights involves Key-Value cache optimization. Keep prompt prefixes stable and make context append-only to dramatically reduce inference costs. When identical context prefixes can be cached and reused, you’re not just saving compute—you’re enabling entirely new interaction patterns that would otherwise be prohibitively expensive.

2. Action Space Management: Mask, Don’t Remove#

Rather than dynamically adding and removing tools mid-conversation, use “masking” to constrain action selection while maintaining context stability. This approach keeps the system predictable while still adapting to current state.

3. File System as Ultimate Context#

Use the file system as your “ultimate context” store. This provides a durable, structured way to maintain state that survives beyond individual conversations. It also enables sophisticated compression strategies where detailed information can be dropped while preserving pathways to restore it when needed.

4. Attention Manipulation Through Structure#

The Manus team introduces practical techniques for guiding model attention:

  • Todo lists that help models “recite objectives”
  • Keeping failed actions in context to enable learning from mistakes
  • Introducing controlled randomness to prevent repetitive behavior loops

These aren’t just prompting tricks—they’re systematic approaches to context design that shape how models process and prioritize information.

5. Context as Experimental Science#

Perhaps the most important meta-lesson: context engineering is fundamentally experimental. Prioritize adaptability over perfection, treating context as a “dynamic, learnable environment.” We’re not trying to design perfect context upfront—we’re building systems that can evolve and improve their context management over time.
